# VLSI Projects — Verilog HDL

Self-directed learning project focused on VLSI Physical Design.
Designed and simulated digital circuits using Verilog HDL on EDA Playground.

## Tools Used
- Verilog HDL
- EDA Playground (Icarus Verilog 12.0)
- EPWave waveform viewer
- VS Code with Verilog HDL extension

## Projects

### Basic Logic Gates
Implemented and simulated AND, OR, NAND, NOR, XOR gates with testbenches.

### Combinational Circuits
- Half Adder — 1-bit addition with Sum and Carry outputs
- Full Adder — 1-bit addition with Carry input and output
- 2:1 Multiplexer — data selector with select line control

### Sequential Circuits
- D Flip Flop — edge triggered storage element with async reset
- 4-bit Counter — counts 0 to 15 on rising clock edge with reset

## Skills Demonstrated
- Verilog module design and instantiation
- Testbench writing and simulation
- Waveform analysis
- Sequential and combinational circuit design
